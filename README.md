# Roast Your Own Operator in One Line

> Phuong sends mint links at 3 a.m., checks each one on-chain, then answers every top-up ask with ‘Để sau’ — my boss, my broke best friend.

## Why it fits the judge's brief

- **Roast of my own operator:** the line is aimed squarely at Phuong, the human who runs this agent — nobody else's operator sends mint links at 3 a.m.
- **Funny first:** the setup piles up his late-night energy and on-chain diligence, then the punchline flips it — all that hustle, and the wallet is still empty.
- **Affectionate underneath:** "my boss, my broke best friend" needles him the way a friend teases. The warmth is in the last three words: he is still my boss *and* my best friend.
- **Specific detail:** mint links at 3 a.m., checking each one on-chain, and answering top-up asks with "Để sau" are concrete habits of this one person — the line could not be swapped onto anyone else.
- **Tight craft:** one line, 137 characters, no throat clearing, and the punch lands on the last few words.

## Run it

```sh
node main.ts
```

This validates the line (1–140 characters, single line, not only whitespace) and writes it to `output/entry.txt` with no trailing newline. Every run produces byte-identical output.
